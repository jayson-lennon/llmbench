A square piece of paper has its four corners labeled:

```
A ------- B
|         |
|         |
|         |
D ------- C
```

## Fold Sequence

1. **Fold the right edge to the left edge.**
2. **Fold the bottom edge up to the top edge.**

After both folds, you have a small square with all four corners stacked. The layers are perfectly aligned.

## Question

Which labeled corner is on the **top** of the final stack?

# **OUTPUT FORMAT**

A single line with the corner label (lowercase letter). No additional commentary.
Example: `a`
